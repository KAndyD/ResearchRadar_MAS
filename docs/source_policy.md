# Политика источников

| Источник | Назначение | Реализация и LIVE-проверка | Ограничение |
| --- | --- | --- | --- |
| OpenAlex | Междисциплинарный поиск научных метаданных | Адаптер реализован; получены три записи | Метаданные не доказывают истинность исследования; полный текст не извлекается. |
| Crossref | Проверка DOI и библиографических данных, дополнительный поиск | Только проектный источник; адаптера нет | Регистрация DOI не означает рецензирование. |
| arXiv | Специализированный поиск препринтов | Только проектный источник; адаптера нет | Препринт не обязательно прошёл рецензирование. |
| GDELT | Широкий новостной поиск | Адаптер реализован; LIVE-запрос вернул HTTP 429 | Получение данных в проверенной среде не подтверждено; новости требуют независимой проверки. |
| Google News RSS | Резервный агрегированный поиск новостей | Адаптер реализован; получены три записи | Агрегация не удостоверяет достоверность новости. |

Каждая нормализованная запись сохраняет тип материала, источник, первичный идентификатор, заголовок, URL, доступную дату, DOI и аннотацию при наличии, объём доступного текста и происхождение (`live_api`, `cache_gdelt` или `synthetic_fixture`). Отсутствие полного текста явно отражается через `text_scope`; DOI и дата могут отсутствовать. Дедупликация по `(source, source_id)` не объединяет материалы разных источников по смысловому сходству. Ошибка одного адаптера не стирает данные другого. DEMO-записи синтетические и не служат доказательством доступности внешних API.
