# Политика источников

| Источник | Назначение | Реализация и LIVE-проверка | Ограничение |
| --- | --- | --- | --- |
| OpenAlex | Междисциплинарный поиск научных метаданных | Адаптер реализован; в проверке этапа 2 получены три записи | Метаданные не доказывают истинность исследования; полный текст не извлекается. |
| Crossref | Проверка DOI и библиографических данных, дополнительный поиск | REST-адаптер реализован; получены три записи | Регистрация DOI не означает рецензирование. Публичный пул имеет ограничения скорости; email для polite-пула задаётся только пользователем. |
| arXiv | Специализированный поиск препринтов | Atom-адаптер реализован; получены три записи | Препринт не обязательно прошёл рецензирование; между повторными запросами соблюдается пауза. |
| GDELT | Широкий новостной поиск | Адаптер реализован; LIVE-запрос вернул HTTP 429 | Получение данных в проверенной среде не подтверждено; новости требуют независимой проверки. |
| Google News RSS | Основной агрегированный поиск новостей | Адаптер реализован; в проверке этапа 2 получены три записи | Агрегация не удостоверяет достоверность новости; RSS не является гарантированно стабильным поисковым API. |

Каждая нормализованная запись сохраняет тип материала, источник, первичный идентификатор, заголовок, URL, доступную дату, DOI/arXiv ID, авторов, издание и аннотацию при наличии, объём доступного текста, происхождение и список источников обнаружения. Отсутствие полного текста явно отражается через `text_scope`. Дедупликация объединяет только точный нормализованный DOI либо одинаковый идентификатор внутри источника; похожее название не является достаточным основанием. При объединении сохраняются источники обнаружения. Ошибка одного адаптера не стирает данные другого. DEMO-записи синтетические и не служат доказательством доступности внешних API.

Актуальные ограничения API проверялись по [документации OpenAlex](https://help.openalex.org/api/authentication/), [правилам доступа Crossref](https://www.crossref.org/documentation/retrieve-metadata/rest-api/access-and-authentication) и [руководству arXiv API](https://github.com/arXiv/arxiv-docs/blob/develop/source/help/api/user-manual.md). Для Crossref без предоставленного пользователем email используется публичный пул; массовый опрос не выполняется. Для arXiv реализована последовательная пауза не менее трёх секунд между запросами одного экземпляра адаптера.
