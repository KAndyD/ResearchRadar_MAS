# Проверки версии 1.2 — 30 октября 2026

## Версия 2.0 — 30 октября 2026

- Windows 11, Python 3.14.7: `py -3.14 -m unittest discover -s tests -q` — 33 теста прошли. Старые 21 регрессионный тест сохранены; 12 новых проверяют оба механизма, маршруты, ошибки и таймауты, нормализацию источников, кэш и план Qwen с подменённым клиентом. Платных вызовов в тестах нет.
- Offline DEMO: оба механизма завершают все пять задач на фиксированных синтетических материалах. Для центрального назначения — 10 сообщений; Contract Net — 44. Типы материалов и идентификаторы сохраняются; обе политики дают одинаковые материалы в базовом сценарии.
- Эксперимент: четыре сценария, 12 пар повторов, 96 запусков. `experiments/results/raw.csv` содержит каждое измерение, `paired.json` — парные разности. Источник времени — `perf_counter`; параметры задержек повторяются по seed, wall time зависит от ОС. Восемь образцов трасс очищены от содержимого материалов.
- LIVE stage2: OpenAlex, Crossref, arXiv и Google News RSS ответили в одном запуске. С Qwen система сформировала альтернативный запрос, завершила 5/5 задач, получила 12 научных записей и 3 новости; суммарно 44 сообщения. Отдельный запуск без Qwen завершил 4/4 задач. `audit_evidence/stage2_live_summary.json` содержит безопасную сводку. GDELT в этом запуске не использовался; последняя его проверка дала HTTP 429.
- Qwen: два новых реальных вызова. Первый дал пустой `content` и подтверждённый расход 0,0002644 USD; после исправления параметров второй дал валидный поисковый план с расходом 0,0000297 USD. Итого на этапе 0,0002941 USD. Ранний подтверждённый расход 0,0004112 USD; общий известный 0,0007053 USD, один старый вызов без данных стоимости. Ключ и SQLite-журнал не в Git.
- Итоговые PDF и DOCX построены из одного исходного набора данных и проверены структурно. PDF содержит 7 страниц, векторные схемы и графики, постранично осмотрен после исправления переполнения таблицы. DOCX содержит 5 встроенных SVG; независимый рендер DOCX недоступен без LibreOffice.
- GitHub Actions: push-проверка коммита `c0b8c47` (run `41038236997`) успешна на Windows/Python 3.14: установка, 33 теста, DEMO старого и двух новых режимов, одно повторение эксперимента. Теговая проверка выполняется после публикации `lab2-v1.0`.

## История первой версии

- Windows 11, Python 3.14.7: `py -3.14 -m unittest discover -s tests -v` — 21 тест прошёл локально. Тесты используют имитацию платного API и не требуют ключа OpenRouter. Очищенный протокол находится в `audit_evidence/test_results.txt`.
- Offline DEMO: две синтетические записи разных типов, четыре агента в фазе `done`, шесть сообщений, ошибок и платных вызовов нет. Сводка без случайных ID и временных меток — `audit_evidence/demo_summary.json`.
- Аудит маршрутов выявил возможность засчитать повторный ответ одного поискового агента вместо ответа другого. Координатор теперь сверяет `correlation_id` с ID назначенной задачи и принимает только один ответ от исполнителя; добавлен тест регрессии.
- LIVE-результаты версии 1.1 не переобъявлялись новым испытанием: OpenAlex — три записи; GDELT — HTTP 429; Google News RSS — три записи при явном резервном режиме; отдельный Qwen-вызов — успешный ответ. Подробности и расходы — `docs/api_validation.md`.
- PDF/DOCX пересобраны из `tools/build_report.py`; PDF содержит векторные схемы, DOCX — два встроенных SVG. PDF проверен постранично. Независимый DOCX-рендерер требует отсутствующий LibreOffice; содержимое DOCX и встраивание SVG проверены структурно.
- GitHub Actions для версии 1.2: push-коммит `575d1de3c6d538dbddd2702a9fb271587cd3fbac`, run `40978530750` — успешно; установка, 21 тест и DEMO прошли на Windows/Python 3.14. Теговый запуск будет проверен после публикации.
