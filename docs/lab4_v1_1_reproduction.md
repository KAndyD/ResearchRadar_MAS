# Воспроизведение исправленного доказательного контура

## Среда и основной запуск

Windows 11, Python 3.14. Для всех обязательных проверок OpenRouter и сеть не требуются. Установить `py -3.14 -m pip install -e .`, затем:

```powershell
py -3.14 -m unittest discover -s tests -v
py -3.14 -m researchradar.cli_stage4 'multi agent systems' --mode demo --analysis recorded --recorded-analysis data/lab4_v1.1_fixture_analysis.json --output run_output/lab4_v1_1_demo.json
py -3.14 tools/verify_lab4_results.py experiments/lab4/results
py -3.14 tools/verify_lab4_llm_results.py experiments/lab4/llm_results
py -3.14 tools/run_lab4_v1_1_llm_experiments.py --output run_output/lab4_v1_1_llm_replay
py -3.14 tools/verify_lab4_v1_1_llm_results.py run_output/lab4_v1_1_llm_replay
py -3.14 tools/verify_lab4_v1_1_live.py
```

Исторические 100 трасс находятся в `experiments/lab4/results/`; их 118 файлов вместе с историческим LLM-корпусом и графиками имеют исходные SHA-256 в `audit_evidence/lab4_v1.1_original_hashes.json`. Новые данные расположены только в `experiments/lab4_v1_1/`. `cases.json` задаёт ожидаемые исходы до выполнения нового стенда. `live/` и `live_round2/` содержат все шесть реально полученных ответов и подтверждённые расходы; `live_manual_review.json` отдельно описывает человеческую качественную оценку трёх пригодных ответов. Повторная проверка сохранённых ответов не делает новых вызовов.

## История LIVE-проверки

Первый отдельный вызов версии 1 — сохранённый реальный ответ с неточной составной цитатой; стоимость 0,00042185 USD. Для исправленной схемы выполнены три коротких вызова на реальных материалах: все три отклонены за чрезмерно длинное объяснение, что зафиксировано. После уточнения инструкции выполнены три вызова на тех же материалах: три результата стали пригодной предварительной аналитикой. Общий подтверждённый расход шести новых вызовов 0,00172399 USD. Удачные ответы не заменяют первые неудачные.

`tools/run_lab4_v1_1_live.py --execute` делает **три новых платных вызова** и требует сохранённый локальный результат поиска `run_output/lab4_v1_1_ocean_search.json`; при обычном воспроизведении его запускать не следует. Сохранённые реальные ответы уже приложены. Ключ хранится только в локальной конфигурации вне архива.

## Архив без Git

Аудиторский ZIP можно распаковать за пределами репозитория. `vendor/wheels/` содержит версии Python-зависимостей для Windows/Python 3.14 с их wheel-метаданными. `tools/audit_lab4_archive.py` создаёт чистый Python venv, устанавливает пакет и зависимости только из локальных wheel-файлов с `--no-index`, скрывает Git из PATH, проверяет путь импорта, полный набор тестов, DEMO, малый диверсионный прогон, новый LLM-корпус, записанные LIVE-ответы и SHA-256 членов. При отсутствии `.git` экспериментальные метаданные честно записывают `protected_code_commit: null` с причиной. Новые запуски идут в `run_output/`, исторические измерения не перезаписываются.
