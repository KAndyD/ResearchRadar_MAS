## Проверка без сети и Git

Из корня распакованного аудиторского ZIP на Windows/Python 3.14:

```powershell
py -3.14 -m pip install -e .
py -3.14 -m unittest discover -s tests -q
py -3.14 -m researchradar.cli_stage3 "multi agent systems" --mode demo --resource-policy baseline --credits 4 --slots 1 --output run_output/slot_conflict.json
py -3.14 tools/run_negotiation_experiments.py --repeats 1 --output run_output/lab3_smoke
py -3.14 tools/verify_lab3_results.py --results run_output/lab3_smoke
```

В `slot_conflict.json` ожидаются один завершённый двухкредитный договор, один `failure`, `spent=2`, `held=0`, `active=0`, `peak_active=1`. Тесты работают offline; повторный платный Qwen-запрос и LIVE-API не нужны. В ZIP находятся исходный корпус и `ARCHIVE_MANIFEST.txt` с SHA-256 каждого члена, архивным коммитом и отдельным коммитом первоначального измерения `8144ef765e839a03ecccc3a9d88e39f1c6a2783e`.

## Границы

При занятом слоте система выбирает немедленный контролируемый отказ. Автоматическая очередь и повторное назначение проверки не реализованы; новый договор может быть создан позднее отдельным запуском. Исходные измерения относятся к явно синтетическим материалам и прежним сценариям с настройкой слотов по умолчанию. Времена отдельного контрольного прогона не заменяют опубликованные миллисекунды. Новостное утверждение без полного текста остаётся непроверенным, а тематическое совпадение — предварительной оценкой.
